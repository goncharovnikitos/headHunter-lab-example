# Лабораторная работа: анализ резюме HeadHunter

Лабораторная работа по исследованию, преобразованию и очистке данных о резюме соискателей.

## Структура

- `assignment/assignment.md` — задание для выполнения лабораторной работы.
- `ATTRIBUTION.md` — информация об исходном материале, использованном при подготовке задания.

## Темы работы

В рамках лабораторной работы рассматриваются:

- загрузка и первичный анализ данных;
- преобразование текстовых признаков;
- выделение признаков из составных полей;
- One Hot Encoding;
- приведение заработной платы к единой валюте;
- исследование распределений;
- анализ зависимостей между признаками;
- визуализация данных;
- обработка пропусков;
- поиск дубликатов и выбросов;
- очистка данных.
